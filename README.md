# 📈 AI-Powered Live Trading Bot

A robust Python-based algorithmic trading system that processes live market data and executes automated trading strategies using a pre-trained AI model (`ai_trading_brain`).

### 🚀 Key Features
* **Live Market Analysis:** Consumes real-time data to calculate indicators like RSI, EMA, and True Range.
* **AI Decision Making:** Utilizes a custom machine learning model to predict market movements and automate buy/sell signals.
* **Risk Management:** Eliminates emotional trading by strictly following logical, data-driven parameters.

### 🛠️ Tech Stack
* **Language:** Python
* **Core Logic:** Pandas, Data Extraction, Machine Learning (Pickle)
* **Focus:** Automation & Algorithmic Trading
